4. **Resource preview images lack explicit width/height on resources.html** (317 `.resource-preview` `<img>` elements)
   - All 317 have `loading="lazy" decoding="async"` but none carry `width` or `height` attributes
   - Without explicit dimensions, the browser cannot reserve layout space → potential CLS on initial load
   - Same issue present on ctfs.html (~39 images), conferences.html (~27), presentations.html (~15)
   - Fix: add `width="300" height="158"` (or actual dimensions) to `<img class="resource-preview">` elements
